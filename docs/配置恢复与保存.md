# 配置恢复与保存指南

本文档适用于 Alpha146 及以上版本，用于在配置异常后恢复历史项目，或手动建立配置检查点。

## 用户恢复步骤
1. 打开 Windows 主窗口，进入“偏好设置” → “配置与存储”。面板在 VR 未启动或离线时依然可用。
2. 在备份列表中查看历史记录。参考记录时间、工作区名称以及屏幕与窗口数量，选取重置发生前的有效时间点。损坏或不可读的快照会自动禁用。
3. 点击“恢复备份”。界面进入待确认状态，初次点击不会修改任何运行配置或磁盘文件。若需放弃，点击“取消恢复”即可退出待确认状态并保留当前列表选择。
4. 确认目标快照信息无误后，点击“确认恢复”。若确认指令已过期，系统将拒绝执行以防止误操作。
5. 如需主动保存当前状态，可随时点击“备份配置”建立检查点。

## 自动保留与回滚机制
- 执行恢复前，系统自动将当前磁盘原件与内存快照归档至历史记录，并将合法的当前内存配置另存至 `.before-restore.json`。
- 若恢复过程发生异常且用户没有进行后续编辑，系统将自动回滚至恢复前的内存源。先前失败的自动保存不会阻断用户执行显式恢复。
- 历史快照按内容哈希自动去重，单配置最多保留 32 个快照或 32 MiB，超出上限自动清理旧快照。最新单份快照若自身超出限制仍予保留。显式拒绝的原文件与手动备份不计入此保留上限。

## 恢复范围与数据边界
- 恢复范围包含项目工作区、偏好设置、窗口布局及小组件会话状态。独立的小组件定义与 MOD 业务数据相互独立，不受影响。
- 系统支持从 `vr-workspaces.json.invalid`、`.bak`、`.backup.json`、`.recovery`、`.before-restore.json`、`.before-defaults.json` 及 `vr-workspaces.json.history` 中读取恢复点。
- 无副本边界说明：系统无法凭空恢复已被覆盖且未留存任何副本的数据。若存储介质中不存在上述任何有效保留副本，系统无法保证找回数据。
