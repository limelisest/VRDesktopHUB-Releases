# Alpha145 更新说明

**发布日期**：2026-10-25

## 核心改动

- **扩展 SDK API1.11 与 API1.12**：提供呈现状态、输入模式与内容归属只读查询及版本号；支持有界宿主操作查询与取消，规范化失败原因与实际上下文；新增动作来源校验，入队仅代表受理而不等同执行成功；新增 `management.surfaces` 独立声明全局/实例范围、VR/Windows 显示端及设置/连接用途；VR 端复用既有设置界面，Windows 端仅展示包管理、允许的实例页与显式连接页，租约与草稿保持独立；兼容策略内的旧 API1.x 与 v1 请求响应保持保留。
- **扩展异常隔离与健壮性**：执行器确认成功后，刷新或完成回调异常不会中断服务或丢失已确认状态；应用关闭时未决操作记录中断状态且不重复执行；WPF 管理面板重排正确解绑旧父级并保留草稿。
- **统一操作栏设置区折叠**：默认折叠未启用选项，已启用项保持外露，新开启项收拢后追加至外露序列末尾；展开与右侧操作保持固定空间锚点；采用原有按钮高亮，不增加勾选遮罩；工作区拼接与聚焦切换始终收纳于设置折叠区内。
- **独立鼠标与触控模式**：工作区与手部小窗独立保存各自的鼠标或触控模式；实际命中目标决定当前模式，按住拖拽保持起始模式；小窗换手、应用重启与复制均保留对应模式。
- **可选使用帮助面板**：移除强制新手引导与独立试用弹窗，改为单份可选的帮助面板；收录 13 个自由选择的主题并恢复 7 项基础操作说明，采用左侧列表与右侧带编号细节布局，支持独立滚动，覆盖手部小窗、操作栏、键盘及小部件，无完成门禁。
- **交互提示精简**：仅提示当前下一可用分支操作；抓握时显示摇杆缩放提示，直接调整尺寸或当前缩放时不显示冗余提示，移除不必要的括号提示文本。
- **手部小窗关闭统一**：操作栏最右侧向下动作统一为直接关闭窗口，完整保留业务数据、尺寸与挂点，关闭后不留边框且指向原位不触发唤醒；自动隐藏机制保持独立。
- **键盘修饰键锁定逻辑**：Shift、Ctrl、Alt、Win 单击仅作用于下一次普通按键；300 毫秒内连续两次短击进入持续锁定，再次单击解锁；慢于 300 毫秒的双击保持取消逻辑，输入其他按键打断双击序列；物理按住、组合键与异常清理规则保持不变。
- **表盘解耦自动吸附**：表盘不再作为吸附源或吸附目标；加载旧配置时仅清除直连表盘的吸附边，完整保留佩戴挂点、手动移动缩放及其余面板吸附关系。
- **生态独立维护**：VRC 工具箱保持在独立项目维护，不随本版本分发。
